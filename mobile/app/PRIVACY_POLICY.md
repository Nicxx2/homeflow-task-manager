# Privacy Policy for Homeflow Mobile

Homeflow Mobile is a companion app for self-hosted Homeflow task management.

The app connects to the Homeflow server URL configured by the user. Task data, household member data, overdue task information, completion status, and account data are stored on the user's own Homeflow server.

Homeflow Mobile does not operate a hosted backend service for user task data. The app does not sell personal data and does not include third-party advertising.

Data the app may access or store:
- The Homeflow server URL entered by the user.
- Login/session details needed to connect to the user's Homeflow server.
- Task and household information provided by the connected Homeflow server.
- Local app preferences, such as whether overdue tasks are shown in the Today view.
- Notification and widget data needed to show task reminders on the user's device.

Notifications and widgets are used only to show task-related information from the connected Homeflow server.

## Data Deletion

Homeflow Mobile does not operate a hosted backend service for user task data. Task data and account data are stored on the user's own self-hosted Homeflow server.

Users who want to delete their data should delete it from their own Homeflow server or contact the administrator of the Homeflow server they use.
